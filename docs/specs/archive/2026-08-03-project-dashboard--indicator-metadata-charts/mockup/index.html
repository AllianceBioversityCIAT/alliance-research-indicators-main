Project Dashboard — Indicator-metadata charts (Chunk B mockup)

Resolves the proposal's blocking layout question B-R1 / B-10: how the dashboard absorbs 10 new cards on top of the 7 that exist today, without turning the page into an undifferentiated grid.

The answer: the new cards do not join the existing Result analytics grid. They live in a new Indicator metadata section, split into one collapsible band per indicator. A band is the unit of visibility (D-7), so a project with no OICR results simply has no OICR band — and the user never scrolls past empty cards to reach populated ones.

Not rendered on this project (D-7): Innovation Use, Knowledge Product, Other Outcome — any indicator with zero results on the project contributes no band and no cards to the DOM. This is distinct from the Stage in Policy Process card above, where the indicator has results but the field is unanswered on all of them — that card renders with an explanatory empty state so the user can tell "nobody filled this in" apart from "this doesn't apply here".

Decisions this mockup locks in

M-1 — Bands, not one flat grid. Ten cards appended to the existing grid would produce 17 undifferentiated tiles. One band per indicator keeps each chart next to the indicator it describes, and gives D-7 a natural unit to hide.

M-2 — Band order follows result volume (descending), so the project's dominant indicator is first. Card order within a band follows the acceptance criteria's order.

M-3 — Chart layout by cardinality. columns (vertical bars) for ≤ 4 categories, rows (horizontal bars) for 5+ or long labels. Both are existing layout() variants — no new chart component (B-7).

M-4 — Bands are collapsible, defaulting to open. With four bands open the section is long but scannable; collapsing is the escape hatch for projects reporting on every indicator.

M-5 — Gender card carries a provenance footnote stating that individual and group trainings are both included (mitigates B-R3's mixed-unit concern while satisfying the AC literally).

M-6 — Degree card carries a filter pill making the two-condition scope (Training + Long-term) visible on the card, so a reader never mistakes it for all degrees (B-R4).

Still open for /akili-specify: whether band collapse state persists across navigation; exact copy for each card description; whether the band header count is "results" or "results with this indicator".
